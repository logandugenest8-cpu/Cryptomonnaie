Connecter votre compte Kraken au bot

Guide pas à pas pour débutant

1

🔐 Créer un compte Kraken

Si vous n’avez pas encore de compte, rendez-vous sur Kraken et inscrivez-vous. Vérifiez votre identité (KYC) pour pouvoir trader.

🔗 Aller sur Kraken
2

🔑 Générer une clé API

Dans votre compte Kraken :
1. Allez dans Sécurité → API
2. Cliquez Créer une clé
3. Cochez uniquement : Query + Trade
4. ⚠ Ne cochez jamais Withdraw !

3

📄 Copier vos clés dans le fichier .env

Ouvrez le fichier .env dans votre dossier et remplissez :

KRAKEN_API_KEY=votre_clé
KRAKEN_API_SECRET=votre_secret
ANTHROPIC_API_KEY=votre_clé_claude

Sauvegardez le fichier.

4

🧩 Tester en simulation d’abord

Dans le fichier .env, gardez :
PAPER_TRADING=true

Le bot va analyser les vrais marchés mais ne dépensera pas votre argent. Observez pendant 1–2 semaines avant de passer en réel.

5

▶️ Lancer le bot

Dans votre terminal, dans le dossier du bot :

pip install -r requirements.txt
puis
python multi_agent_main.py

Le bot tourne en arrière-plan et analyse toutes les heures.

6

🟢 Passer en trading réel

Quand vous êtes confiants, changez dans .env :
PAPER_TRADING=false

⚠ Commencez avec un petit montant ! Réglez aussi :
PORTFOLIO_SIZE_USD=500
MAX_POSITION_PCT=5

Glossaire — Les termes expliqués simplement

Pas de jargon incompréhensible ici

RSI
Mesure si une crypto est trop achetée ou trop vendue. En dessous de 30 = braderie, au dessus de 70 = euphorie.
MACD
Indicateur de tendance. Quand il croise vers le haut, c’est souvent un signal d’achat. Vers le bas = signal de vente.
EMA (Moyenne Mobile)
Ligne lissée du prix moyen sur les dernières heures. Utile pour voir si le marché monte ou descend globalement.
Stop-Loss
Filet de sécurité. Si le prix tombe à ce niveau, le bot vend automatiquement pour éviter de perdre trop.
Take-Profit
L’objectif de gain. Quand le prix atteint ce niveau, le bot vend pour encaisser les bénéfices.
Paper Trading
Trading en simulation avec de l’argent fictif. Permet de tester le bot sans risquer votre vrai argent.
Order Book
Le carnet d’ordres. Liste de tous les acheteurs et vendeurs du moment. Utile pour voir qui domine le marché.
Market Regime
L’état actuel du marché : Haussier (monte), Baissier (descend), Neutre (stagne), Volatile (sauvage).
API Kraken
Un accès sécurisé que Kraken vous donne pour que le bot puisse passer des ordres à votre place.
