🔐 Compte Kraken

Inscrivez-vous sur Kraken. Accepte les virements SEPA en euros depuis un compte français.

🔗 Kraken.com
2

🔑 Clé API

Sécurité → API → Créer.
Cochez : Query + Trade
⚠ Jamais Withdraw !

3

📄 Fichier .env

KRAKEN_API_KEY=xxx
KRAKEN_API_SECRET=xxx
ANTHROPIC_API_KEY=xxx
PORTFOLIO_SIZE_EUR=1000

4

🧩 Simulation

Gardez PAPER_TRADING=true. Le bot analyse les vrais marchés sans dépenser vos euros. Observez 1–2 semaines.

5

▶️ Lancer le bot

pip install -r requirements.txt
python scheduler.py
Le scheduler lance le bot + les rapports 4h + le rapport hebdo automatiquement.

6

🟢 Trading réel

PAPER_TRADING=false
⚠ Commencez petit !
PORTFOLIO_SIZE_EUR=200
MAX_POSITION_PCT=5

Glossaire
RSI
Indicateur de survente/surachat. <30 = opportunité, >70 = attention.
Stop-Loss
Vente automatique si le prix tombe ici. Protège vos euros.
Take-Profit
Le bot vend ici pour encaisser vos gains en euros.
Paper Trading
Simulation avec euros fictifs. Zéro risque pour votre vrai argent.
Rapport 4h
Résumé automatique de l’état des trades toutes les 4 heures.
Rapport hebdo
Bilan gains/pertes de la semaine + ajustements automatiques du bot.
