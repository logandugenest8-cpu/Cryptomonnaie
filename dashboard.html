1

🔐 Créer un compte Kraken

Inscrivez-vous sur Kraken. Kraken accepte les virements bancaires en euros directement depuis un compte français (SEPA).

🔗 Aller sur Kraken
2

🔑 Générer une clé API

Dans Kraken : Sécurité → API → Créer une clé.
Cochez uniquement : Query + Trade
⚠ Ne cochez JAMAIS Withdraw !

3

📄 Remplir le fichier .env

KRAKEN_API_KEY=votre_clé
KRAKEN_API_SECRET=votre_secret
ANTHROPIC_API_KEY=votre_clé_claude
PORTFOLIO_SIZE_EUR=1000

4

🧩 Tester en simulation

Gardez PAPER_TRADING=true dans votre fichier .env. Le bot analyse les vrais marchés en euros mais ne dépense pas votre argent. Observez 1–2 semaines.

5

▶️ Lancer le bot

pip install -r requirements.txt
puis
python multi_agent_main.py
Le bot analyse toutes les heures et écrit dans agent_state.json.

6

🟢 Passer en réel

Changez PAPER_TRADING=false
⚠ Commencez petit !
PORTFOLIO_SIZE_EUR=200
MAX_POSITION_PCT=5

Glossaire
RSI
Mesure si une crypto est trop achetée (>70) ou trop vendue (<30) en euros.
Stop-Loss
Le bot vend automatiquement si le prix tombe ici, pour limiter vos pertes en euros.
Take-Profit
Le bot vend ici pour encaisser vos gains en euros.
Paper Trading
Simulation avec des euros fictifs. Aucun risque pour votre vrai argent.
MACD
Indicateur de tendance. Croisement vers le haut = signal d’achat potentiel.
API Kraken
Clé d’accès que Kraken vous donne pour que le bot passe des ordres en euros.
